# 🎬 VideoHub Frontend

Modern frontend for a YouTube-style video platform built with React.js.

## Features
- Responsive UI
- User Authentication
- Video Feed
- Video Player
- Likes / Comments
- Subscribe / Unsubscribe
- Search
- Profile & Channel Pages
- Dark / Light Mode

## Tech Stack
React.js • Tailwind CSS • React Router • Axios
